# Super Renováveis

Protótipo de apresentação (tema diurno) inspirado nos dossiês Maranta: transição energética, renováveis, BESS e comunicação. Versão completa fica pra depois.

## Como rodar

```bash
npm install
npm run dev
```

Abra **http://127.0.0.1:4732**

Controles: ← → ou A/D mover · Z / Espaço / ↑ pular · pegue as **baterias** (verde/teal) pra recarregar energia · no castelo qualquer tecla avança o diálogo
